# ADR-0014 ノード間の中継（効率のよい通信）

- 状態: 採用（2026-11-03）
- 関係: 仕様 8.3、REQ-010 R10-7・R10-9、ADR-0013

## 決定

- ノードの組ごとに **1 本の多重化した接続**（mTLS の TCP。QUIC が入ったら QUIC のストリーム・DATAGRAM へ）。stream・トラックごとに論理チャネルを持つ。
- **購読の集約**: あるノードで同じ stream を見る購読者が何人いても、ノード間で運ぶのは 1 回。受けたノードの hub が中で配る（中継の木）。
- **運ぶのは符号化済みの AU だけ**（生のフレームは運ばない）。payload は `Bytes` のまま、見出しは小さな二進形式（可変長整数）。
- **優先度と背圧**: 音声 > 映像のキーフレーム > それ以外。詰まったら、低い優先度から捨て、映像は次のキーフレームまで捨てる（壊れた GOP を送らない。仕様 5.3）。サイマルキャストの層は相手ノードの購読者が要るものだけ送る。
- **まとめて送る**: 小さな AU（音声）を短い時間（既定 5 ms 以内）でまとめて 1 回の書き込みにする（システムコールとヘッダーを減らす）。
- 帯域・RTT・捨てた数を計測し、配置の係（ADR-0013）の判断に使う（帯域が足りなければ別の経路・別のノード）。
