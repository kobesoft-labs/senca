# ADR-0010 クラウドのメディア PaaS との連携

- 状態: 採用（2026-11-02）
- 関係: REQ-001、仕様 8.2・9.3、ADR-0007

## 決定

- 連携先は出力の一種（`protocol: "paas"`、`provider`: `cloudflare_stream`・`aws_ivs`・`aws_medialive`）。配送の中核は SENCA のまま。
- 要求の組み立て・応答の解析・SigV4 は senca-paas（sans-io）。通信はノード（外向きの HTTPS、宛先の制限つき）。
- **二重に作らない**: 作る前・途中の経過（checkpoint）を `provider_resource` に保存してから要求を送る。外部の資源には `senca:owner`（出力 ID）・`senca:cluster` のタグを付け、記録の無い資源はタグで見つけて引き取る。
- **秘密は保存しない**: 受け口の stream key・パスフレーズは、送る前に毎回 `get` で取り直す。資格情報は秘密値（ADR-0007）。
- 送るのは既存の rtmp_push（RTMPS）・srt_push。
- **後片付け**: 出力を消すと外部の資源も消す（MediaLive は Input とセキュリティグループ）。SENCA のタグの無い資源は消さない。
- 資格情報の形: Cloudflare は `account_id:api_token`、AWS は `access_key_id:secret_access_key[:session_token]`（`options.region`）。

## 未了
