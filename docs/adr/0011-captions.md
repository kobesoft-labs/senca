# ADR-0011 字幕と翻訳

- 状態: 採用（2026-11-02）
- 関係: REQ-006 R6-4、ADR-0004、REQ-005（外部処理）

## 決定

- stream の `captions` に、音声認識（`openai`＝OpenAI 互換の /audio/transcriptions、`whisper_cpp`）と翻訳（`anthropic`・`deepl`・`openai`）の送り先・資格情報（秘密値）・言語を設定する。**設定が無ければ外部へは何も送らない。**
- 音声は**復号しない**。AAC は音声だけの MP4（m4a）、Opus は Ogg にそのまま詰め替えて送る（送り先が復号する。ADR-0004）。5 秒の窓・1 秒の重なり。
- 認識の結果は重なりを統合して確定した字幕にし、言語ごとの WebVTT の HLS 字幕（`sub_{lang}.m3u8`・`sub_{lang}_{msn}.vtt`）と `master.m3u8`（`EXT-X-MEDIA TYPE=SUBTITLES`）を出す。字幕の区切りは映像のセグメントと同じ。
- **字幕は遅れて出てよい方式**（映像は遅らせない）。認識に数秒かかるので、届いた時点で閉じたセグメントより前の字幕は、開いているセグメントの時刻へずらして出す。映像を遅らせて合わせる方式（`DelayVideo`）の見積もりは senca-caption にあるが、ノードでは未実装。
- 認識・翻訳は 1 本ずつ、配信の受信とは別のタスク。遅れたら音声のチャンクを捨てる（字幕が欠けるだけで配信は止めない）。
- API キーはログ・エラーに出さない。
