# REQ-007 ロイヤリティフリー（特許料のかからない）技術への対応

- 追加日: 2026-10-26（利用者の指示「特許フリーな技術にも対応。色々な事情を加味する」）
- 状態: 要件として受理。

## 要件

1. ロイヤリティフリーとして提供されている技術に対応する。
2. **「ロイヤリティフリーのみ」プロファイル**を選べる。選んだ場合、H.264 / H.265 / AAC など特許プールのある技術を使う設定・変換計画は、理由付きで拒否する（黙って使わない）。
3. 事情（顧客の方針、配布先の国、端末の対応状況、ハードウェアの有無）に応じて、プロファイルをテナント・stream ごとに選べる。

## 対象

| 種類 | ロイヤリティフリーとして提供 | 特許プールあり（従来） |
|---|---|---|
| 映像 | AV1、VP9、VP8 | H.264、H.265 |
| 音声 | Opus、FLAC、（Vorbis） | AAC |
| 入れ物 | WebM（Matroska）、fMP4（ISO BMFF）、MPEG-TS | — |
| 静止画 | PNG、WebP、AVIF、JPEG（基本方式） | HEIF（HEVC） |
| 実装（外部コーデック） | libaom / SVT-AV1 / dav1d、libvpx、libopus（いずれも BSD 系） | x264（GPL）、openh264 など |

## 注意（保証の範囲）

- AV1・VP9・VP8・Opus は開発元がロイヤリティフリーで提供している。ただし第三者のパテントプール（例: Sisvel の AV1/VP9 プール）が権利を主張している例があり、**「特許がない」ことは保証しない**。製品の表示は「ロイヤリティフリーとして提供されている技術」とし、採用判断は法務確認の対象とする（仕様 9.5 のコーデック特許の確認と同じ扱い）。
- コーデックごとの根拠（ライセンス文書、取得日、版）を ADR とライセンス台帳に保存する。

## 経路ごとの対応

| 経路 | ロイヤリティフリーでの形 | 必要な実装 |
|---|---|---|
| WebRTC | VP8 / VP9 / AV1 + Opus | P3（M8）。VP8 は仕様 5.4 の初期対象 |
| MoQ | AV1 / VP9 + Opus（catalog で宣言） | M10 |
| HLS | fMP4（CMAF）で AV1 / VP9 + Opus | fMP4 muxer（M11 を前倒し候補） |
| RTMP | Enhanced RTMP の AV1 / VP9 / Opus | E-RTMP（M11） |
| SRT | TS に Opus（ETSI TS 102 366 の方式）、AV1 は採用版を確認 | M7 |
| 録画 | WebM または fMP4 | M2 の後に追加 |
| 静止画・サムネイル | PNG / WebP / AVIF | M4 |

## 受け入れ試験（案）

| ID | 内容 | 合格条件 |
|---|---|---|
| AC-R7-01 | ロイヤリティフリーのみのプロファイルで H.264 入力を設定 | 変換計画が理由付きで拒否、または AV1/VP9 への変換を提示 |
| AC-R7-02 | AV1 + Opus を WebRTC・HLS(fMP4)・録画へ | 独立実装（Chrome、ffmpeg）で再生でき、フレームが一致 |
| AC-R7-03 | 配布物の検査 | プロファイル用の配布物に特許プール対象のコーデック実装が含まれない（SBOM で確認） |
